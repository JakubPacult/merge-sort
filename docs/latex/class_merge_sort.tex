class Merge\+Sort$<$ T $>$}
Klasa szablonowa implementująca algorytm sortowania przez scalanie (Merge Sort). 

Algorytm działa w oparciu o strategię „dziel i zwyciężaj” (divide and conquer), gwarantując złożoność obliczeniową O(n log n) w każdym przypadku.
